Privacy policy

Last updated: 18 November 2026

comment-bot is a private tool used only by the owner of the YouTube channel ผีติดหู to read and reply to comments on that channel's own videos.

What data it uses

  • Public comments posted on the channel's videos: comment text, the commenter's public display name, the video title and the time posted.
  • The channel owner's own YouTube sign-in token, which lets the tool read comments and post replies as the channel.

How the data is used

  • Comments are processed on the owner's own computer by a local AI model to sort them and draft replies.
  • Replies are posted only on the channel's own videos, as the channel.
  • Data is not sold, shared with third parties, used for advertising, or sent to any outside AI service.

Storage

Comments and replies are kept in a local file on the owner's computer so the same comment is not answered twice. Nothing is stored on any server run by this tool.

Google user data

comment-bot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The channel owner can remove the tool's access at any time at myaccount.google.com/permissions.
